---
title: "CLI: hannam과 hnc"
description: .hn을 바로 실행하는 hannam과 .js로 컴파일하는 hnc를 설명합니다.
---

`hannam-lang` 패키지는 명령어 두 개를 제공합니다. `hnc`는 hannam compiler의 줄임말로, TypeScript의 `tsc`(TypeScript compiler)와 같은 방식으로 지은 이름입니다.

| 명령어 | 역할 | 비슷한 도구 |
| --- | --- | --- |
| `hannam app.hn` | `.hn`을 메모리에서 변환해 바로 실행 | `node`, `tsx` |
| `hnc app.hn` | `.hn`을 `.js` 파일로 컴파일 | `tsc` |

## hannam: 바로 실행

```sh
hannam app.hn [인자...]
```

- `.hn` 파일끼리 `import "./util.hn"`처럼 확장자를 붙여 가져옵니다. 확장자 없는 상대 경로 import는 그대로 실행하지만, `.hn`을 가리키려던 실수일 수 있어 `hannam: 경고:`로 알려 줍니다.
- 파일 이름 뒤의 인자는 프로그램에 그대로 넘어갑니다(`process.argv`).
- 에러 스택은 소스맵으로 `.hn` 원본의 줄과 칸을 가리킵니다.
- 컴파일 에러가 나면 위치와 코드 조각을 출력하고 종료 코드 1로 끝납니다.

### Node 로더 훅으로 실행

`hannam` 명령 대신 Node에 로더 훅을 직접 등록해도 됩니다. 다른 Node 옵션과 함께 쓸 때 편합니다.

```sh
node --import hannam-lang/register app.hn
```

## hnc: 컴파일

```sh
hnc <파일|디렉터리...> [옵션]
```

| 옵션 | 설명 |
| --- | --- |
| `-o`, `--out-dir <dir>` | 출력 디렉터리. 디렉터리 인자는 그 안의 폴더 구조를 유지합니다 |
| `--source-map` | `.js.map` 파일을 함께 만듭니다 |
| `-h`, `--help` | 도움말을 출력합니다 |
| `-v`, `--version` | 버전을 출력합니다 |

```sh
hnc src --out-dir dist --source-map
```

- 기본으로 원본 옆에 `.js`를 만듭니다. 디렉터리를 주면 그 안의 `.hn`을 모두 찾습니다(`node_modules` 제외).
- 상대 경로 import의 `.hn`은 `.js`로 바뀝니다(`"./store.hn"` → `"./store.js"`). 자세한 규칙은 [모듈](/docs/syntax/modules)에 있습니다.
- 런타임 헬퍼가 필요한 파일은 맨 끝에 `import { __hn } from "hannam-lang/runtime"`이 붙습니다. 출력물을 실행할 프로젝트에 `hannam-lang`을 의존성으로 설치해 주세요. 자세한 내용은 [런타임](/docs/syntax/runtime)에 있습니다.
- 출력은 ES 모듈입니다. Node로 실행한다면 `package.json`에 `"type": "module"`을 넣어 `.js`를 ES 모듈로 읽게 합니다.

## 변환기 API

빌드 도구를 직접 만들 때는 변환기를 함수로 부를 수 있습니다.

```js
import { compile, HannamSyntaxError } from "hannam-lang"

try {
  const { code, map } = compile(source, { filename: "app.hn" })
} catch (e) {
  if (e instanceof HannamSyntaxError) {
    console.error(e.message) // 위치와 코드 조각이 들어 있습니다
  }
}
```

| 옵션 | 기본값 | 설명 |
| --- | --- | --- |
| `filename` | 없음 | 에러 메시지와 소스맵에 쓸 파일 이름 |
| `rewriteImports` | `false` | 상대 경로 import의 `.hn`을 `.js`로 바꿉니다 |
| `runtimeImport` | `"hannam-lang/runtime"` | 런타임 헬퍼를 가져올 모듈 이름 |

돌려주는 `map`은 소스맵 객체이고 `toString()`, `toUrl()`을 쓸 수 있습니다. 같은 API가 `@hannam-lang/core` 패키지에도 있습니다.
