---
title: Bun에서 실행
description: Bun 플러그인으로 .mz를 Bun에서 바로 실행합니다.
---

Node 로더 훅(`mzscript/register`)은 Bun에서 동작하지 않습니다. 그래서 Bun용 플러그인을 따로 제공합니다.

## 설치

```sh
bun add -d mzscript
```

## 실행

`--preload`로 플러그인을 먼저 불러온 뒤 `.mz` 파일을 실행합니다.

```sh
bun --preload mzscript/bun app.mz
```

매번 옵션을 쓰기 번거로우면 `bunfig.toml`에 등록합니다.

```toml title="bunfig.toml"
preload = ["mzscript/bun"]
```

```sh
bun app.mz
```

`.mz` 파일끼리 import하는 방법은 Node와 같습니다. 경로에 `.mz` 확장자를 붙여 주세요.
