<Steps>
<Step>

### 파일 만들기

`hello.mz` 파일을 만들고 다음 코드를 적습니다.

```mz title="hello.mz"
엄... 첫 엠지스크립트 프로그램
엄.. 이름 = "엠지스크립트"
엄. 개수 = 3

티-원 인사(누구) {
  아! 줴줴이야~ `안녕, ${누구}!`
}

무슨 발언이세요? 인사(이름)

요이~ i 0..개수 {
  예? i === 1 {
    아뇨
  }
  무슨 발언이세요? `${i}번째 반복`
}
```

</Step>
<Step>

### 실행하기

`mz`는 `.mz`를 메모리에서 JS로 바꿔 바로 실행합니다. Node의 `node`나 `tsx`와 같은 역할입니다.

```sh
mz hello.mz
```

```txt
안녕, 엠지스크립트!
0번째 반복
2번째 반복
```

</Step>
<Step>

### 변환 결과 보기

`mzc`는 `.mz`를 `.js` 파일로 컴파일합니다. TypeScript의 `tsc`와 같은 역할입니다.

```sh
mzc hello.mz
```

원본 옆에 생긴 `hello.js`는 다음과 같습니다. 엠지스크립트 키워드만 JS로 바뀌고 나머지는 그대로입니다.

```js title="hello.js"
// 첫 엠지스크립트 프로그램
const 이름 = "엠지스크립트"
let 개수 = 3

function 인사(누구) {
  return `안녕, ${누구}!`
}

console.log(인사(이름))

for (let i = 0; i < 개수; i++) {
  if (i === 1) {
    continue
  }
  console.log(`${i}번째 반복`)
}
```

</Step>
</Steps>
