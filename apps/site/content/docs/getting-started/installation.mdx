## 요구 사항

- **Node.js 20.16 이상**. `hannam`이 쓰는 로더 훅(`module.register`)과 터미널 확인 창 기능이 이 버전부터 동작합니다.
- Bun에서 실행하려면 Node 로더 훅 대신 Bun 플러그인을 씁니다([Bun에서 실행](/docs/getting-started/bun)). `hannam`, `hnc` 명령 자체는 Node로 실행됩니다.

## 프로젝트에 설치

`hannam-lang` 패키지 하나에 실행기 `hannam`, 컴파일러 `hnc`(hannam compiler), 런타임 헬퍼가 모두 들어 있습니다.

```npm
npm i -D hannam-lang
```

처음 설치하면 그 시점의 최신 버전이 깔리고, `package.json`에는 `^0.1.0` 같은 범위가 기록됩니다. 그래서 새로 설치할 때는 `@latest`를 붙이지 않아도 됩니다. 이미 설치한 프로젝트를 최신 버전으로 올릴 때는 범위를 새로 쓰도록 `@latest`를 붙입니다.

```npm
npm i -D hannam-lang@latest
```

`hnc`로 컴파일한 `.js`를 배포한다면, 출력물이 `hannam-lang/runtime`을 import할 수 있으므로 `-D` 없이 일반 의존성으로 설치합니다.

## 전역으로 설치

어느 폴더에서나 `hannam app.hn`을 실행하고 싶다면 전역으로 설치합니다.

<Tabs items={["npm", "pnpm", "yarn", "bun"]}>
  <Tab value="npm">
    ```sh
    npm install -g hannam-lang
    ```
  </Tab>
  <Tab value="pnpm">
    ```sh
    pnpm add -g hannam-lang
    ```
  </Tab>
  <Tab value="yarn">
    ```sh
    yarn global add hannam-lang
    ```
  </Tab>
  <Tab value="bun">
    ```sh
    bun add -g hannam-lang
    ```
  </Tab>
</Tabs>

`yarn global add`는 Yarn 1(classic) 명령입니다. Yarn 2 이상에서는 전역 설치 대신 프로젝트에 설치해서 씁니다.

설치가 끝나면 버전을 확인합니다.

```sh
hannam --version
hnc --version
```

## 함께 쓰면 좋은 것
