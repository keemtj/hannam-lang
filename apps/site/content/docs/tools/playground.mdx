[Playground](/playground)는 TypeScript Playground처럼 `.hn` 코드를 입력하면 바로 JS로 바꿔 보여 주고, 실행 결과를 콘솔에 띄웁니다.

## 기능

- **나란히 보기**: 왼쪽에 `.hn`, 오른쪽에 변환된 JS가 나옵니다. 컴파일 에러가 나면 에디터에 위치를 표시하고, 마지막으로 성공한 JS를 흐리게 보여 줍니다.
- **실행**: 실행 버튼을 누르면 결과가 아래 콘솔에 나옵니다. `예? 무슨 발언이세요?(...)`(confirm)는 브라우저 확인 창을 띄웁니다.
- **예제**: 문법별 예제를 골라 불러올 수 있습니다.
- **공유 링크**: 코드를 압축해 주소의 `#code/...` 부분에 담습니다. 링크를 열면 같은 코드로 시작합니다.
- **테마**: 라이트·다크 테마를 바꿀 수 있고, 처음에는 사이트 테마를 따릅니다.

## 안전하게 실행하는 방법

코드는 부모 페이지와 분리된 샌드박스 iframe에서 실행합니다.

- iframe에 `allow-same-origin` 권한이 없어서 이 사이트의 쿠키, 저장소, DOM에 접근할 수 없습니다.
- 무한 루프는 두 겹으로 막습니다. 반복문이 한 번의 실행에서 3초 넘게 멈추지 않고 돌면 에러를 내고 실행을 멈춥니다(확인 창이 떠 있던 시간은 빼고 셉니다). 반복문 밖에서 멈춘 경우에도 일정 시간 신호가 없으면 iframe을 없앱니다.

## 문서 안의 "실행해 보기"

문법 문서 곳곳에 있는 작은 실행 블록도 같은 컴포넌트입니다. 블록 안에서 코드를 고쳐 실행해 볼 수 있고, 공유 링크를 누르면 전체 Playground로 이동합니다.

<TryIt code={"요이~ i 1..4 {\n  무슨 발언이세요? `${i}번째: 요이~`\n}\n"} />
