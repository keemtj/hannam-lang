title: JS에서 옮겨 오기

---

한남랭은 JS 상위 호환이라서 JS 파일의 확장자만 `.hn`으로 바꿔도 대부분 그대로 동작합니다. 그다음 밈이 있는 문법을 하나씩 밈으로 바꾸면 됩니다.

## 옮기는 순서

<Steps>
<Step>

### 확장자 바꾸기

`app.js`를 `app.hn`으로 바꿉니다. 다른 `.js` 파일을 가져오던 상대 경로도 `.hn`으로 바꿉니다(`"./store.js"` → `"./store.hn"`). 확장자 없는 상대 import는 컴파일 에러이므로 이때 함께 고칩니다.

</Step>
<Step>

### 실행해서 확인하기

`hannam app.hn`으로 실행하거나, Vite 프로젝트라면 [Vite 플러그인](/docs/getting-started/vite)을 등록합니다. 한남랭 규칙에 걸리는 곳이 있으면 컴파일 에러가 위치와 함께 알려 줍니다.

</Step>
<Step>

### 문장 키워드를 밈으로 바꾸기

아래 대응표를 보고 문장 맨 앞의 키워드를 밈으로 바꿉니다. 한 번에 다 바꾸지 않아도 됩니다. 밈과 JS 키워드를 섞어 써도 변환 결과는 같습니다.

</Step>
</Steps>

## 대응표

| JS | 한남랭 |
| --- | --- |
| `var x = 1` / `let x = 1` / `const x = 1` | `엄 x = 1` / `엄. x = 1` / `엄.. x = 1` |
| `// 주석` | `엄... 주석` |
| `if (a) {` / `} else if (b) {` / `} else {` | `예? a {` / `} 예?? b {` / `} 아뇨아뇨아뇨아뇨 {` |
| `switch (x) { case 1: ... break }` | `예??? x { 1 { ... } }` |
| `for (const a of list) {` | `요이~ a list {` |
| `for (let i = 0; i < n; i++) {` | `요이~ i 0..n {` |
| `for (const k in obj) {` | `요히~ k obj {` |
| `while (cond) {` | `요이이이~ cond {` |
| `break` / `continue` | `줴줴이야` / `아뇨` |
| `function f() {` / `async function f() {` | `티-원 f() {` / `티~원 f() {` |
| `await p` | `티~원! p` |
| `return x` | `아! 줴줴이야~ x` |
| `throw new Error("msg")` | `아... 줴줴이야... "msg"` |
| `try {` / `} catch (e) {` | `진~지? {` / `} 지~랄 e {` |
| `class A {` / `class B extends A {` | `오호호호호~ A {` / `오호호호홋~ B A {` |
| `console.log(a, b)` | `무슨 발언이세요? a, b` |
| `confirm("질문")` | `예? 무슨 발언이세요?("질문")` |

## 옮길 때 주의할 점

### switch는 갈래로 다시 씁니다

`예???`에는 `case`와 `break`가 없습니다. 갈래 하나가 `값 { ... }` 블록 하나이고, fallthrough로 여러 값을 묶던 코드는 쉼표로 묶습니다.

```js
switch (필터) {
  case "완료":
  case "보관":
    보여줄것 = 완료목록
    break
  default:
    보여줄것 = 전체목록
}
```

```hn
예??? 필터 {
  "완료", "보관" {
    보여줄것 = 완료목록
  }
  아뇨아뇨아뇨아뇨 {
    보여줄것 = 전체목록
  }
}
```

`예???`는 if-else로 바뀌기 때문에, 갈래 안의 `줴줴이야`(break)는 바깥 반복문을 빠져나갑니다. 반복문 밖에서 쓰면 JS 에러가 납니다.

- 갈래 **끝**의 `break`는 지우면 됩니다. 갈래가 다음 갈래로 넘어가지 않기 때문입니다.
- 갈래 **중간**에서 조건에 따라 switch만 빠져나가던 `break`는 지우기만 하면 안 됩니다. `예?` 조건으로 나머지 코드를 감싸거나, 함수로 빼서 `아! 줴줴이야~`(return)로 빠져나가도록 다시 짭니다.

### throw는 항상 Error가 됩니다

`throw "문자열"`처럼 문자열을 던지던 코드를 `아... 줴줴이야... "문자열"`로 바꾸면 `new Error("문자열")`을 던집니다. `catch`에서 문자열을 그대로 비교하던 코드는 `e.message`를 비교하도록 바꿔 주세요.

### CommonJS는 ES 모듈로 바꿉니다

한남랭의 출력은 항상 ES 모듈입니다. `require`, `module.exports`, `__dirname`을 쓰는 CommonJS 코드는 `import`, `export`, `import.meta.url`로 바꿔 주세요. 상대 경로 import에는 확장자를 붙입니다.

### 이름으로 쓸 수 없는 것

`줴줴이야`와 `아뇨`는 예약어라서 변수 이름으로 쓸 수 없습니다. 반면 `엄`이라는 이름의 변수는 쓸 수 있습니다. `엄 = 1`, `엄.length`처럼 뒤에 공백과 변수 이름이 오지 않으면 일반 JS로 읽습니다.

### 밈이 없는 문법은 그대로

화살표 함수, `async` 화살표, `finally`, `do...while`, `for await`, `import`/`export`, 모든 연산자는 바꾸지 않습니다. [문법 한눈에 보기](/docs/syntax)의 "JS 그대로 쓰는 문법"을 참고하세요.
