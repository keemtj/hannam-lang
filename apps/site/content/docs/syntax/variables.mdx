---
title: 변수와 주석
description: 엄 가족(엄, 엄., 엄.., 엄...)으로 변수를 선언하고 주석을 씁니다.
---

점이 하나씩 늘어날수록 다른 문법이 됩니다.

| 엠지스크립트 | JS |
| --- | --- |
| `엄 이름 = 값` | `var 이름 = 값` |
| `엄. 이름 = 값` | `let 이름 = 값` |
| `엄.. 이름 = 값` | `const 이름 = 값` |
| `엄... 내용` | `// 내용` |

```mz
엄... 할 일 목록
엄.. 할일들 = []
엄. 개수 = 0
엄 전역설정 = null
```

```js
// 할 일 목록
const 할일들 = []
let 개수 = 0
var 전역설정 = null
```

## 공백이 꼭 필요합니다

`엄`, `엄.`, `엄..` 뒤에는 반드시 공백과 변수 이름(또는 구조분해 패턴)이 와야 합니다. 그래야 `엄`이라는 이름의 변수를 쓰는 일반 JS와 구분됩니다.

```mz
엄... const 선언
엄.. 이름 = "엠지스크립트"
엄... '엄'이라는 변수의 length를 읽는 일반 JS
엄.length
```

## 구조분해

객체와 배열 구조분해를 그대로 쓸 수 있습니다.

```mz
엄.. 할일 = { 내용: "장보기", 완료: false }
엄.. { 내용, 완료 } = 할일
엄.. [첫째, ...나머지] = [1, 2, 3]
```

```js
const 할일 = { 내용: "장보기", 완료: false }
const { 내용, 완료 } = 할일
const [첫째, ...나머지] = [1, 2, 3]
```

## 주석

`엄...`은 줄 주석(`//`)입니다. 문장 맨 앞, 그리고 클래스 본문·객체·괄호 안의 줄 맨 앞에서 쓸 수 있습니다. JS의 `//`, `/* */` 주석도 그대로 씁니다.

<Callout type="warn" title="말줄임표 한 글자(…)는 다른 글자입니다">
  `엄...`은 마침표 3개입니다. 휴대폰 키보드가 자동으로 바꾼 `엄…`(말줄임표 한 글자)은 컴파일 에러가 납니다. 에러 메시지가 "마침표 3개로 바꾸세요"라고 알려 줍니다.
</Callout>
