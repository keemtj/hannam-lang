| 한남랭 | JS |
| --- | --- |
| `티-원 이름(인자) {` | `function 이름(인자) {` |
| `티~원 이름(인자) {` | `async function 이름(인자) {` |
| `티~원! 표현식` | `await 표현식` |
| `아! 줴줴이야~ 값` | `return 값` (값 생략 가능) |
| `아... 줴줴이야... 값` | `throw 값` (문자열이면 Error로 감쌈) |

이겼을 때의 `아! 줴줴이야~`는 값을 돌려주고(return), 졌을 때의 `아... 줴줴이야...`는 에러를 던집니다(throw).

## 함수, return, throw

```hn
티-원 할일추가(내용) {
  예? !내용.trim() {
    아... 줴줴이야... "빈 할 일"
  }
  할일들.push({ id: Date.now(), 내용, 완료: false })
  아! 줴줴이야~ 할일들.length
}
```

```js
function 할일추가(내용) {
  if (!내용.trim()) {
    throw new Error("빈 할 일")
  }
  할일들.push({ id: Date.now(), 내용, 완료: false })
  return 할일들.length
}
```

## 값 없는 return

값을 생략하면 그냥 `return`입니다. 함수 앞부분에서 조건이 맞지 않을 때 빠져나가는 가드로 자주 씁니다.

```hn
티-원 삭제(id) {
  예? !id {
    아! 줴줴이야~
  }
  할일들.splice(할일들.findIndex(할일 => 할일.id === id), 1)
}
```

```js
function 삭제(id) {
  if (!id) {
    return
  }
  할일들.splice(할일들.findIndex(할일 => 할일.id === id), 1)
}
```

## 값은 같은 줄에

`아! 줴줴이야~`와 `아... 줴줴이야...`의 값은 **같은 줄**에 있어야 합니다. JS `return`의 자동 세미콜론 규칙과 같습니다. 줄을 바꾼 뒤의 값은 다음 문장으로 봅니다.

한 줄 블록에서는 같은 줄의 `}` 앞에서 값이 끝납니다.

```hn
예? !항목 { 아! 줴줴이야~ }
```

값이 길면 JS처럼 줄 끝을 연산자·쉼표로 끝내거나, 다음 줄을 `.`·`?.`·연산자로 시작해서 이어 씁니다.

## throw는 항상 Error를 던집니다

`아... 줴줴이야...`는 문자열을 그대로 던지지 않고 항상 Error 객체를 던집니다.

| 한남랭 | JS |
| --- | --- |
| `아... 줴줴이야... "빈 할 일"` | `throw new Error("빈 할 일")` |
| ``아... 줴줴이야... `${id}번 없음` `` | ``throw new Error(`${id}번 없음`)`` |
| `아... 줴줴이야... 에러` (타입을 모르는 값) | `throw __hn.toError(에러)` |
| `아... 줴줴이야... new 검증에러("...")` | `throw new 검증에러("...")` (그대로) |

- 문자열과 템플릿 리터럴은 컴파일할 때 `new Error(...)`로 바로 바뀝니다. 런타임 헬퍼를 거치지 않아서 스택 트레이스가 깔끔합니다.
- 변수처럼 타입을 모르는 값은 런타임 헬퍼 `__hn.toError`를 거칩니다. 문자열이면 Error로 감싸고, Error 객체는 그대로 던집니다.

## async와 await

`티~원`은 async 함수, `티~원!`은 await입니다.

```hn
티~원 불러오기(url) {
  엄.. 응답 = 티~원! fetch(url)
  예? !응답.ok {
    아... 줴줴이야... "불러오기 실패"
  }
  아! 줴줴이야~ 티~원! 응답.json()
}
```

```js
async function 불러오기(url) {
  const 응답 = await fetch(url)
  if (!응답.ok) {
    throw new Error("불러오기 실패")
  }
  return await 응답.json()
}
```

- `티~원!`은 값 위치에서도 씁니다. 템플릿의 `${}` 안에서도 됩니다(`` `${티~원! 개수()}개` ``).
- 출력이 ES 모듈이므로 함수 밖에서도 `티~원!`을 쓸 수 있습니다.

## 화살표 함수와 메서드는 JS 그대로

화살표 함수, async 화살표 함수, 객체·클래스 메서드는 JS 문법 그대로 씁니다.

```hn
엄.. 두배 = (x) => x * 2
폼.addEventListener("submit", async (e) => {
  e.preventDefault()
})
```
