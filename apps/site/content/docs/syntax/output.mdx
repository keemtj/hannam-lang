## 출력: `무슨 발언이세요?`

- 문장 시작 위치에서만 인식합니다.
- 쉼표로 여러 값을 넘길 수 있습니다. `무슨 발언이세요? a, b`는 `console.log(a, b)`가 됩니다.
- 값은 여러 줄로 이어 쓸 수 있습니다. 줄이 연산자·쉼표로 끝나거나 다음 줄이 `.`·`?.`·연산자로 시작하면 같은 값으로 읽습니다.
- **띄어 쓰는 형태만 씁니다.** `무슨 발언이세요?("a")`처럼 괄호를 붙이면 컴파일 에러가 나고, 띄어 쓰라고 알려 줍니다.
- `무슨 발언이세요? (a, b)`처럼 쉼표 목록을 괄호로 감싸면 컴파일 에러입니다. JS 쉼표 연산자가 되어 `b`만 출력되기 때문입니다. `무슨 발언이세요? (a + b) * 2`처럼 계산을 묶는 괄호는 괜찮습니다.
- `무슨 발언이세요??`처럼 물음표 개수가 다르거나 띄어쓰기가 다른 형태는 컴파일 에러입니다.

## 확인: `예? 무슨 발언이세요?(질문)`

- 값 위치에서 인식하고, 사용자의 답에 따라 `true` 또는 `false`를 돌려줍니다.
- 브라우저에서는 `window.confirm` 창을 띄우고, Node에서는 터미널에서 y/n을 입력받습니다.
- if 조건으로 쓸 때는 `예?`를 한 번 더 써서 `예? 예? 무슨 발언이세요?(질문) {`로 씁니다.

<Callout type="warn" title="if 조건에서는 예?를 두 번">
  문장 맨 앞의 `예? 무슨 발언이세요?(질문) {`는 컴파일 에러입니다. 가장 긴 형태 우선 규칙에 따라 앞의 `예? 무슨 발언이세요?`를 확인 창으로 읽기 때문입니다. 에러 메시지가 `예? 예? ...`로 쓰라고 알려 줍니다.
</Callout>

- 텍스트 입력(`prompt`)에는 엠지스크립트 키워드가 없습니다. 필요하면 `prompt()`를 JS 그대로 씁니다.
