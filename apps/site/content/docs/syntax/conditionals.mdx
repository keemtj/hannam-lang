물음표 개수가 다르면 다른 문법입니다.

| 한남랭 | JS |
| --- | --- |
| `예? 조건 {` | `if (조건) {` |
| `} 예?? 조건 {` | `} else if (조건) {` |
| `} 아뇨아뇨아뇨아뇨 {` | `} else {` |
| `예??? 값 {` | `switch` (아래 참고) |

## if · else if · else

```hn
예? 개수 === 0 {
  무슨 발언이세요? "할 일 없음"
} 예?? 개수 < 5 {
  무슨 발언이세요? "여유 있음"
} 아뇨아뇨아뇨아뇨 {
  무슨 발언이세요? "바쁨"
}
```

```js
if (개수 === 0) {
  console.log("할 일 없음")
} else if (개수 < 5) {
  console.log("여유 있음")
} else {
  console.log("바쁨")
}
```

- 조건 괄호는 선택입니다. `예? (개수 === 0) {`도 됩니다.
- `예??`(else if)는 `예?` 블록을 닫는 `}` 바로 뒤에서만 씁니다. 따로 쓰면 컴파일 에러입니다.
- `아뇨아뇨아뇨아뇨`(else)는 **정확히 4번** 반복합니다. 1번(`아뇨`)은 반복문의 continue이고, 2번·3번·5번은 컴파일 에러입니다.
- 물음표는 1~3개만 씁니다. `예????`처럼 4개 이상이면 컴파일 에러입니다.

<Callout title="왜 엄격하게 에러를 내나요?">
  `아뇨아뇨`나 `예????` 같은 형태를 JS로 그냥 넘기면, JS 파서가 엉뚱한 위치에서 알아보기 어려운 에러를 냅니다. 그래서 한남랭이 먼저 정확한 위치와 함께 알려 줍니다.
</Callout>

## 헤더는 첫 `{` 직전까지

조건(헤더)은 괄호 깊이 0에서 처음 나오는 `{` 직전까지입니다. `()`, `[]` 안의 `{`는 무시하므로 조건 안에 화살표 함수를 써도 되고, 조건을 여러 줄로 써도 됩니다.

```hn
예? 할일들.some(할일 => { 아! 줴줴이야~ 할일.완료 }) {
  무슨 발언이세요? "끝낸 일이 있음"
}
```

조건이 객체 리터럴로 시작하면 괄호로 감싸야 합니다(`예? ({ a: 1 }).a {`).

## switch: `예???`

물음표 3개는 switch입니다. `case` 키워드 없이 `값 {` 하나가 갈래 하나입니다.

```hn
예??? 필터 {
  "전체" {
    보여줄것 = 할일들
  }
  "완료", "보관" {
    보여줄것 = 할일들.filter(할일 => 할일.완료)
  }
  아뇨아뇨아뇨아뇨 {
    보여줄것 = 할일들.filter(할일 => !할일.완료)
  }
}
```

```js
{ const __hn_s0 = 필터;
  if (__hn_s0 === "전체") {
    보여줄것 = 할일들
  }
  else if (__hn_s0 === "완료" || __hn_s0 === "보관") {
    보여줄것 = 할일들.filter(할일 => 할일.완료)
  }
  else {
    보여줄것 = 할일들.filter(할일 => !할일.완료)
  }
}
```

- 값 여러 개는 쉼표로 묶습니다. 갈래가 다음 갈래로 넘어가는 fallthrough가 없어서 `break`가 필요 없습니다.
- 비교는 JS `switch`와 같은 `===`이고, 대상 값은 한 번만 평가합니다.
- `default`는 `아뇨아뇨아뇨아뇨`입니다. 반드시 마지막 갈래에 씁니다.
- 갈래 값에 연산자가 있으면 괄호로 감싸서 비교합니다(`1 || 5 {` → `__hn_s0 === (1 || 5)`). 식별자, 리터럴, `a.b` 같은 멤버 접근은 그대로 비교합니다.
- 비교할 대상 값은 하나만 씁니다(`예??? a, b {`는 에러). 갈래 사이에 `;`를 쓰지 않습니다.
- 한 줄 갈래도 됩니다: `"전체" { 아! 줴줴이야~ 할일들 }`

### JS switch가 아니라 if-else로 바뀝니다

`예???`는 JS `switch`가 아니라 if-else 체인으로 바뀝니다. 그래서 갈래 안에서 쓴 `줴줴이야`(break)와 `아뇨`(continue)는 **바깥 반복문**에 작동합니다. JS `switch` 안의 `break`가 switch만 빠져나가는 것과 다르니 주의하세요.

전체를 `{ }` 블록으로 감싸서 임시 변수(`__hn_s0`, `__hn_s1` …)가 바깥으로 새지 않습니다.
