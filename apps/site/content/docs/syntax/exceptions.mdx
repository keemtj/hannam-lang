| 한남랭 | JS |
| --- | --- |
| `진~지? {` | `try {` |
| `} 지~랄 e {` | `} catch (e) {` |
| `} 지~랄 {` | `} catch {` (에러 변수 생략) |

`진~지?`로 진지하게 시도해 보고, 누가 `아... 줴줴이야...`로 에러를 던지면 `지~랄`("아 진짜?")로 받아 줍니다.

```hn
진~지? {
  엄.. 할일들 = 티~원! 불러오기("/api/todos")
  무슨 발언이세요? `${할일들.length}개 불러옴`
} 지~랄 e {
  무슨 발언이세요? e.message
} finally {
  로딩중 = false
}
```

```js
try {
  const 할일들 = await 불러오기("/api/todos")
  console.log(`${할일들.length}개 불러옴`)
} catch (e) {
  console.log(e.message)
} finally {
  로딩중 = false
}
```

## 규칙

- 에러 변수의 괄호는 선택입니다. `} 지~랄 e {`와 `} 지~랄 (e) {` 둘 다 됩니다.
- 구조분해도 됩니다. `} 지~랄 { message } {`는 `} catch ({ message }) {`가 됩니다. `{ ... }` 뒤에 `{`가 한 번 더 오면 앞쪽을 에러 변수로 봅니다.
- `지~랄`은 `진~지?` 블록을 닫는 `}` 바로 뒤에서만 씁니다.
- `finally`는 JS 그대로 `} finally {`로 씁니다.
- 형태는 고정입니다. `지랄`, `지-랄`, `진지?`, `진~지`(물음표 없음)는 컴파일 에러입니다.

<Callout title="JS 코드와 겹치지 않을까요?">
  `~`는 JS의 단항 연산자라서 `지~랄`, `진~지`는 원래 JS에서 문법 오류입니다. 그래서 일반 JS 코드와 충돌하지 않습니다.
</Callout>
