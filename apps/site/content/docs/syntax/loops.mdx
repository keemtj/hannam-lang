---

기분 좋을 때 쓰는 `요이~`에서 온 문법입니다.

| 한남랭 | JS |
| --- | --- |
| `요이~ 항목 목록 {` | `for (const 항목 of 목록) {` |
| `요이~ i 0..10 {` | `for (let i = 0; i < 10; i++) {` (끝 미포함) |
| `요히~ 키 객체 {` | `for (const 키 in 객체) {` |
| `요이이이~ 조건 {` | `while (조건) {` |
| `줴줴이야` | `break` |
| `아뇨` | `continue` |

## for...of: `요이~`

헤더의 첫 패턴이 반복 변수이고, 나머지가 대상 식입니다.

```hn
요이~ 할일 할일들 {
  예? 할일.완료 {
    아뇨
  }
  무슨 발언이세요? 할일.내용
}
```

```js
for (const 할일 of 할일들) {
  if (할일.완료) {
    continue
  }
  console.log(할일.내용)
}
```

## 범위: `요이~ i 시작..끝`

`시작..끝`은 끝을 포함하지 않는 범위입니다.

```hn
요이~ i 0..할일들.length {
  무슨 발언이세요? `${i + 1}. ${할일들[i].내용}`
}
```

```js
for (let i = 0; i < 할일들.length; i++) {
  console.log(`${i + 1}. ${할일들[i].내용}`)
}
```

## for...in: `요히~`

`요이`의 `이`를 `히`로 바꾼 짝입니다. 객체의 키를 돕니다.

```hn
엄.. 설정 = { 테마: "다크", 정렬: "최신순" }
요히~ 키 설정 {
  무슨 발언이세요? `${키}: ${설정[키]}`
}
```

```js
const 설정 = { 테마: "다크", 정렬: "최신순" }
for (const 키 in 설정) {
  console.log(`${키}: ${설정[키]}`)
}
```

## 구조분해

반복 변수 자리에 구조분해 패턴을 쓸 수 있습니다.

```hn
요이~ [키, 값] Object.entries(설정) {
  무슨 발언이세요? `${키}=${값}`
}
```

```js
for (const [키, 값] of Object.entries(설정)) {
  console.log(`${키}=${값}`)
}
```

## while: `요이이이~`

`이`가 **정확히 3개**입니다. `요이이~`, `요이이이이~`는 컴파일 에러입니다.

```hn
엄. 남은수 = 3
요이이이~ 남은수 > 0 {
  무슨 발언이세요? 남은수
  남은수--
}
```

```js
let 남은수 = 3
while (남은수 > 0) {
  console.log(남은수)
  남은수--
}
```

## break와 continue

- `줴줴이야`는 `break`, `아뇨`는 `continue`입니다.
- 두 밈은 홀로 한 문장을 이루므로 예약어입니다. 같은 이름의 변수를 만들 수 없습니다.
- `예???`(switch) 갈래 안에서 쓰면 바깥 반복문에 작동합니다([조건문](/docs/syntax/conditionals) 참고).

## 알아 둘 점

- `요이~`, `요히~`, `요이이이~` 뒤에는 공백이 와야 키워드로 인식합니다.
- 물결 없는 `요이`, `요히`는 다음 버전을 위해 예약해 두었습니다.
- `do...while`, `for await`는 JS 그대로 씁니다.
