한국 남자 웃음소리에서 온 문법입니다. 실제 발음은 "오콧콧콧"과 "오홋홋홋" 사이라 한글로 딱 떨어지지 않아서, 표기를 두 형태로 고정했습니다.

| 한남랭 | JS |
| --- | --- |
| `오호호호호~ 이름 {` | `class 이름 {` |
| `오호호호홋~ 이름 부모 {` | `class 이름 extends 부모 {` |

두 형태 모두 다섯 글자이고 마지막 글자(`호`/`홋`)만 다릅니다. 짝으로 기억하기 쉽고 눈으로도 구분됩니다.

```hn
오호호호호~ 할일 {
  constructor(내용) {
    this.내용 = 내용
    this.완료 = false
  }

  토글() {
    this.완료 = !this.완료
    아! 줴줴이야~ this
  }
}

오호호호홋~ 마감할일 할일 {
  constructor(내용, 마감일) {
    super(내용)
    this.마감일 = 마감일
  }
}
```

```js
class 할일 {
  constructor(내용) {
    this.내용 = 내용
    this.완료 = false
  }

  토글() {
    this.완료 = !this.완료
    return this
  }
}

class 마감할일 extends 할일 {
  constructor(내용, 마감일) {
    super(내용)
    this.마감일 = 마감일
  }
}
```

## 규칙

- `오호호호홋~` 헤더는 `요이~`처럼 첫 식별자가 클래스 이름이고, 나머지가 부모 클래스 식입니다.
- 클래스 본문(constructor, 메서드, 필드)은 JS 그대로 씁니다. 메서드 안에서는 다른 밈 문법을 쓸 수 있습니다.
- 끝의 `~`가 꼭 필요합니다. `오호~`, `오호호~`, `오호호호~`, `오호호호호호~`, `오호호호호`(물결 없음), `오콧콧콧~`, `오홋홋홋~` 등은 컴파일 에러입니다.
- 상속은 `오호호호홋~`로만 씁니다. `오호호호호~ 이름 extends 부모 {`는 컴파일 에러입니다.
- `오호호호호~`, `오호호호홋~` 뒤에는 공백이 와야 키워드로 인식합니다.
- 클래스 표현식(`const A = class {}`)은 JS 그대로 씁니다.
