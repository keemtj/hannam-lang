# 투두 풀스택 예제 (초안)

Phase 0 마지막 점검으로, 명세(`docs/hannam-lang-syntax.md`)만 보고 쓴 투두 앱 전체 초안이다. 아직 변환기가 없으므로 Phase 1 스냅샷 테스트와 Phase 4·5 데모의 출발점으로 쓴다.

```
server/server.hn   node:http REST 서버, JSON 파일 저장
web/api.hn         fetch로 서버 API 호출
web/main.hn        화면: 추가, 완료 토글, 삭제(confirm), 필터
web/index.html     <script type="module" src="./main.hn">
```

## API
| 메서드 | 경로 | 동작 |
| --- | --- | --- |
| GET | `/api/todos` | 목록 |
| POST | `/api/todos` | 추가 (`{ "내용": "..." }`, 빈 내용은 400) |
| PATCH | `/api/todos/:id` | 완료 토글 |
| DELETE | `/api/todos/:id` | 삭제 (204) |

## 검증 결과 (2026-10-22)
명세 일부만 처리하는 임시 변환 스크립트로 `.hn`을 JS로 바꿔 확인했다.
- 세 `.hn` 파일 모두 `node --check` 통과
- 서버: 목록, 추가, 빈 내용 400, 토글, 405, 없는 id 404, 삭제 204, 없는 경로 404 모두 기대대로 응답
- 브라우저: 추가, HTML 이스케이프, 토글, 완료 필터, confirm 후 삭제 동작, 콘솔 에러 없음

## 초안을 쓰며 발견한 점
- **async 화살표 함수에 설탕이 없다.** 이벤트 리스너와 `http.createServer` 콜백에서 `async (e) => {`를 세 번 JS 그대로 썼다. 함수 선언은 `티~원`인데 화살표만 `async`라서 섞여 보인다. → 화살표 함수는 일단 JS 그대로 두기로 결정, 설탕은 다음 버전 후보
- **`for await`는 JS 그대로.** 서버에서 요청 본문을 읽을 때 한 번 나온다
- **한 줄 블록이 자주 나온다.** `"전체" { 아! 줴줴이야~ 할일들 }`처럼 `{ }` 안에 문장 하나를 한 줄로 쓰는 형태. return 값이 같은 줄의 `}` 앞에서 끝난다는 규칙이 필요함 (명세에 반영)
- **변환기는 블록 종류를 추적해야 한다.** `예???` 안의 `"GET" {`(갈래)와 일반 블록, `}` 뒤의 `아뇨아뇨아뇨아뇨`(else)와 `예???` 안의 `아뇨아뇨아뇨아뇨`(default)를 구분하려면 지금 열린 블록이 무엇인지 알아야 한다
- **Vite 플러그인은 HTML의 `.hn` 진입점을 처리해야 한다.** `index.html`이 `main.hn`을 직접 불러온다 (Phase 3에서 확인)
